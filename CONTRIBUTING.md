# Contribuir a Live Caption Linux

Gracias por interesarte. Este proyecto es **abierto a la comunidad**: opiniones, ideas, bugs y código son bienvenidos — sobre todo si estás aprendiendo, como yo.

## Formas de aportar (todas valen)

1. **Opinar** — “se me ocurre…”, “en mi distro pasa esto…”, “esto confunde…”
2. **Reportar un bug** — usa la plantilla de issue si puedes
3. **Proponer una idea** — feature, UX, docs, Windows, etc.
4. **Mandar un PR** — aunque sea pequeño (typo, README, test)

## Antes de codear mucho

Abre un **issue** o una **Discussion** con la idea. Así alineamos el rumbo y no duplicamos trabajo. El código en la nube a veces va un poco detrás de lo que tengo en local; si notas desfase, dilo.

## Issues

- Usa las plantillas cuando existan
- Incluye: distro/versión, GPU (si aplica), pasos para reproducir, qué esperabas vs qué pasó
- Capturas o logs ayudan mucho

## Pull requests

1. Fork + rama con nombre claro (`fix/mejor-vad`, `docs/readme-es`, …)
2. Cambios enfocados (un tema por PR)
3. Describe el *por qué* y cómo probarlo
4. Sé amable en el review — esto es un espacio de aprendizaje
